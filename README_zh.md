# Codexia

[English README](README.md)

## 项目介绍

Codexia 是一个 Windows 桌面应用，用于在 Codex 中集中使用 ChatGPT 订阅账号和第三方模型渠道。

![Codexia 概览](docs/screenshots/overview.png)

## 为什么使用

- 将多个 ChatGPT 订阅账号组成账号池，统一提供本地 API 服务。
- 接入 Responses API 第三方渠道，并在 Codex 中统一选择模型。
- 查看账号额度、重置卡、调用统计和预估成本。
- 在额度恢复后自动唤醒无人值守的长任务。
- 按时向已有会话发送消息，或启动新的 Codex 会话执行任务。
- 集中管理 Codex 接入配置和可选的 MCP 服务。

## 快速开始

1. 安装 Codex CLI，并确认 `codex` 命令可用。
2. 打开 `Codexia.exe`。
3. 添加 ChatGPT 订阅账号、模型渠道，或同时添加两者。
4. 打开“接入模式”并应用 API 模式。
5. 在“服务管理”中启动 API 服务。
6. 回到 Codex 选择模型。

API 模式可以同时使用订阅模型和第三方模型；账号模式只使用选中的订阅账号。

## 核心功能

### 订阅账号与模型渠道

订阅账号可以通过浏览器登录，也可以从 Codex 导入。Codexia 支持额度刷新、账号启停、重置卡使用和账号池路由。

第三方渠道可配置 API 地址、API Key、`models.json`、WebSocket、余额查询、请求头和模型费率。使用前可以预览模型目录并运行调用测试；不同渠道的模型 ID 不能重复。除非渠道原生兼容 Codex 压缩接口，通常保持“远程压缩适配”开启。

GPT 账号池在启动和手动刷新时获取官方模型目录，按 Pro、Pro Lite、Plus、Go、Free 的顺序选择账号。获取失败时先使用上次成功的远程目录，再由本机 Codex 内置目录兜底。第三方渠道保留各自的模型配置。可选的 Codex Bundled 覆盖允许使用自定义 JSON 替代账号池目录。

### 接入模式与服务

“接入模式”负责把配置写入 Codex。API 模式使用本地 API 服务；账号模式使用一个订阅账号，也可选择通过现有 API 服务透明代理 `/responses` 请求并纳入调用分析。

“服务管理”用于启动、停止或重启 API 服务和可选的 [`mcp-gateway-service`](https://github.com/jadchene/mcp-gateway)。MCP 服务首次启动前需要配置程序路径和监听地址。设置 `CODEX_HOME` 后，Codexia 会使用该目录中的 Codex 配置；未设置时使用当前用户的 `.codex`。

> 已知限制：Codex CLI 0.154.0 在 API Key 模式下可能不在 `/status` 和状态栏显示额度；额度仍会由网关使用，可在 Codexia“运行概览”查看账号池剩余量。

### 会话唤醒

“会话唤醒”适合夜间无人值守的长任务。登记会话 UUID、生效时段和最大尝试次数：

- 订阅账号池额度耗尽且没有账号可切换时，等待最近的重置时间，刷新确认有额度后再唤醒。
- 启用“恢复 Goal”会重新激活未完成的 Goal；否则发送普通的继续消息。
- 停用、删除、到期或达到尝试上限后停止；等待状态可随应用重启恢复，不确定的投递不会自动重复。

使用期间需保持 Codexia 和对应的 Codex 会话运行，确保本机可执行 `codex`，并使用相同的 `CODEX_HOME`。

### 定时任务

“定时任务”用于按计划向 Agent 发送普通消息：

- 可选择已有会话，或每次在指定工作目录启动新会话。
- 可设置消息、生效时段和启停状态；Cron 生成器支持分钟间隔、每小时、每天和每周，也可直接填写五段表达式。`0 22 * * *` 表示本机时间每天 22 点。
- 同一任务不会重叠执行，重启或休眠期间错过的时间点不会补发；停用或删除不影响已经开始的任务。

发送到已有会话的斜杠命令只会作为普通文本。使用期间需保持 Codexia 运行，已有会话还需使用相同的 `CODEX_HOME`。

### 设置

| 区域 | 可配置内容 |
| --- | --- |
| 常规 | 开机自启、关闭行为、主题和显示密度。 |
| API 与 MCP | 地址、端口、访问密钥、配置文件和自动启动。 |
| 账号与额度 | 刷新策略、账号选择、Session 亲和、失败冷却和额度显示。 |
| 日志与计费 | 记录保留时间、计费币种、数据位置和清理操作。 |
| 高级网络 | 超时、连接数、请求大小和仅支持 HTTP 的模型回退；通常保持默认值。 |

部分服务设置需要重启对应服务后生效。

### 数据、安全与调试

正式版数据保存在应用旁边的 `data/` 目录中。升级时保留该目录，移动或替换应用前先备份；目录中包含账号和渠道配置，请勿分享。

数据库升级前会在 `data/backups/` 创建加密备份，并在 24 小时后自动清理。备份与创建它的 Windows 用户绑定。

API 调试日志默认关闭。开启后，请求和响应正文会临时写入 `data/logs/`，敏感请求头会脱敏；调试最长持续 10 分钟，关闭、到期或退出应用时自动删除。正文可能包含敏感信息，只应在排障时短暂启用。

本项目用于个人本地使用。请使用自己的账号和 API Key，并遵守各服务提供方的条款。

## 开发

需要 Node.js 24 或更高版本。

```bash
npm install
npm run dev
npm run verify
```

生成 Windows 免安装包：

```bash
npm run pack:unpacked
```

输出文件为 `release/win-unpacked/Codexia.exe`。该程序未进行代码签名，也不包含安装器。
